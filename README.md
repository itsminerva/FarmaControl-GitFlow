# FarmaControl

Proyecto desarrollado para la asignatura Programación III.

## Tecnologías

- ASP.NET Core 8
- Entity Framework Core
- SQL Server
- React
- Bootstrap
- Git
- GitHub
- Git Flow

## Funcionalidades

- CRUD de productos
- CRUD de categorías
- CRUD de proveedores
- Gestión de ventas
- Alertas de vencimiento

## Flujo Git

Se implementó la metodología Git Flow utilizando:

- main
- develop
- qa
- feature/*
- hotfix/*
